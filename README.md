## Sobre mim

Sou **Desenvolvedor Full Stack** e **Técnico de Informática**, interessado no desenvolvimento de aplicações web, mobile e sistemas.

Trabalho com diferentes tecnologias do ecossistema moderno de desenvolvimento, desde a construção de interfaces até APIs, bancos de dados, autenticação e integração com serviços externos.

Tenho interesse especial em:

- Desenvolvimento **Full Stack**
- Aplicações Web modernas
- Aplicações Mobile
- APIs e sistemas backend
- Bancos de dados relacionais e NoSQL
- Arquitetura e organização de projetos
- Cloud e serviços backend
- Automação e ferramentas para desenvolvimento
- Aprendizagem contínua e experimentação tecnológica

Alguns dos projetos que fazem parte do meu percurso de desenvolvimento:

- **Portfolio pessoal** — aplicação web para apresentação profissional e projetos.<hr>
- **Movi Angola** — Sistema completo para análise, otimização e recomendação de rotas urbanas em Angola, com foco especial em segurança e eficiência.<hr>
- **Auzaschool** — plataforma educacional com tecnologias web modernas.<hr>
- **AuzaCode** — IDE completa e profissional para desenvolvimento de aplicações, rodando nativamente em Android, iOS, Windows, macOS e Linux.<hr>
- **Yetu Preparatório** — Plataforma para preparação de concursos públicos angolanos (MED, MINSA, MININT e outros).<hr>
- **Nzimbu** — aplicação de gestão financeira pessoal desenvolvida com Flutter.<hr>
- **Kixikila** — Kixikila é uma plataforma digital inovadora para gestão de grupos de poupança coletiva, baseada em **confiança extrema** e transparência total.<hr>
- **GeoClima** — aplicação web integrada com dados meteorológicos e localização.<hr>
- **Sistemas Web / E-commerce** — desenvolvimento de interfaces, APIs, autenticação, banco de dados e gerenciamento de conteúdo.
